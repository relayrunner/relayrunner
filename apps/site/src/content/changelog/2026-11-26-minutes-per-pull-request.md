---
title: Minutes per pull request
date: 2026-11-26
type: Feature
description: Usage has a Pull requests tab with the CI minutes and estimated spend of each pull request, plus the typical pull request.
---

- **Every pull request's minutes.** **Usage › Pull requests** lists each pull request by the CI minutes its jobs ran, across every push and re-run, with re-run minutes, commits and estimated spend beside it. See [Usage](/docs/dashboard/usage#pull-requests).
- **The typical pull request.** Tiles show the median pull request's minutes with its p90 and average, the median spend per pull request, and how much of your CI went to pull requests.
- **Filter by repo.** Pick a repo and every number follows it. The range and repo stay in the URL, so you can share the view.
