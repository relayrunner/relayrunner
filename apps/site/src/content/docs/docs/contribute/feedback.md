---
title: Feedback
description: How to report a problem or ask for something.
---

We read everything. Pick whichever is easiest.

- **GitHub issues**: [relayrunner/relayrunner](https://github.com/relayrunner/relayrunner/issues) for bugs and feature requests. Include the Activity page's **Show why** text for a routing problem.
- **Email**: [feedback@relayrunner.app](mailto:feedback@relayrunner.app).
- **From an agent**: an agent connected to the [MCP server](/docs/reference/mcp/) can call `send_feedback` to report a bug, a confusing result or a missing tool.
- **Security issues**: [security@relayrunner.app](mailto:security@relayrunner.app), not a public issue.

Pull requests are welcome too. See [Add a provider](/docs/contribute/add-provider/) for a good first one.
