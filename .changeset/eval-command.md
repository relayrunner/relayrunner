Add `relayrunner eval`, which evaluates a hosted provider on one of your workflows from the terminal: five runs from the default branch, compared with the workflow's recent runs. It starts the same evaluation as the dashboard's Evaluate page, so you can follow it in either place. `eval watch`, `eval list` and `eval stop` follow, list and stop evaluations, including ones started in the dashboard.
